# Reported results

`cross_dataset.csv` contains the cross-dataset values reported in the manuscript. The repository does not include generated predictions, dataset lists, face crops, or model checkpoints.

The `AVG` columns follow the manuscript and average FF++-C23, DFDC, DFR, Celeb-DFv2, and WDF. When comparing transfer alone, compute a target-only average that excludes FF++-C23 and state that convention explicitly.
